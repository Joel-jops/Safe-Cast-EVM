# Safe Cast – Multi-Factor Smart Electronic Voting Machine

## 📌 Overview

Safe Cast is a secure electronic voting system developed as a final-year B.Tech Computer Science project. The system combines RFID authentication, Email OTP verification, and Facial Recognition to ensure secure and transparent voting.

---

## 🔐 Features

- Email OTP Authentication
- Facial Recognition using OpenCV
- RFID-Based Authentication
- Firebase Cloud Database Integration
- Duplicate Vote Prevention
- Admin Dashboard
- Candidate Registration
- Voter Registration
- Secure Vote Storage

---
